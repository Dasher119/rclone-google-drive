# Personal rclone Google Drive Integration

This page describes a personal OAuth application used exclusively by the owner
to synchronize personal files between a Linux computer and Google Drive using rclone.

The application is not offered as a public service and is not intended for use by third parties.

## Privacy

Google Drive data accessed through this application is used solely to synchronize
the owner's own files between the local computer and the owner's Google Drive account.

No Google user data is sold, shared with third parties, or used for advertising.
Authentication credentials remain under the control of the application owner.
